🌿 3. GitHub 협업 전략 & 개발 마일스톤 (~10/16)

충돌 없는 Unity 프로젝트 관리를 위해 Git 규칙을 준수하며, **10월 16일 축제 부스 전시**를 1차 완공 목표로 설정합니다. 사후 분석 및 보완 로드맵도 포함합니다.

🔀 Branch 전략 (GitHub Flow)
• main: 10/16 전시용 최종 검증 빌드
• develop: 개발 통합 최신 브랜치
• feature/기능명: 개별 기능/장애물 구현
• hotfix/*: 부스 시연 중 버그 즉시 수정
📝 Commit Convention
feat: 신규 기능 (예: 출석 레이저)
fix: 버그 수정 (예: 충돌 판정 오작동)
assets: 3D 모델/사운드 파일 추가
ui: 랭킹 팝업 UI 수정
refactor: 코드 구조 개선
⚠️ Unity Git 필수 주의사항
• Unity 전용 .gitignore 필수 등록 (Library, Temp 제외)
• Project Settings -> Editor -> Visible Meta Files 설정
• 씬(Scene) 충돌 방지를 위해 역할별 전용 작업 씬 분리 후 Prefab화 병합

🎬 4. '길건너' 스타일 장애물 기믹 & 거리별 패턴

단일 맵(등교길)에서 진행되며, 거리가 늘어날수록 길건너 친구들 특유의 기믹(기차, 독수리 등)을 대학 생활 테마로 변형한 장애물들이 차례대로 추가됩니다.

📊 장애물 기믹 요약표 (PPT 전용)

원작 기믹 (길건너 친구들) 대학생 테마 적용 동작 패턴 및 기획 의도
나무, 바위 (정지 길막) 방치된 킥보드, 잡담 무리 이동을 막는 고정형 장애물. 좌우로 우회하여 지나가야 함 (0m부터 기본 배치)
자동차, 트럭 (일반 이동) 자전거, 셔틀버스 도로를 일정한 속도로 횡단. 타이밍을 맞춰 사이로 지나가야 함
기차 (경고 후 초고속 돌진) 배달 오토바이 바닥에 붉은색 경고선 표시 및 경적 소리 후, 눈 깜짝할 새 지나감 (200m 이후 추가 등장)
독수리 (타임아웃 즉사) 교수님의 매의 눈 제자리에 3~5초 이상 머물거나 화면 밖으로 밀리면, 교수님이 등장해 강제 F학점(게임오버) 부여
