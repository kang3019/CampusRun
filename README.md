## 📖 1. 프로젝트 개요 (Project Overview)

**'지각 5분전 (CampusRun)'**은 10월 16일 소프트웨어학과 축제 부스 전시를 목표로 제작된 대학생 공감 3D 탭 아케이드 게임입니다.  
볼거리와 체험 거리가 많은 축제 현장 환경에 맞추어, **1인당 1분 내외의 짧고 직관적인 조작감**과 **기록 경신을 통한 랭킹 경쟁**을 유도하도록 기획되었습니다.

| 항목 | 상세 내용 |
|:---|:---|
| **프로젝트명** | **지각 5분전 - 1교시를 향해 달려라!** (영문 코드명: `CampusRun`) |
| **장르 / 플랫폼** | 3D 하이퍼캐주얼 탭 아케이드 / Windows PC (태블릿 PC & 노트북 최적화) |
| **핵심 마일스톤** | **🎯 2026년 10월 16일 축제 부스 전시 완성 빌드 릴리스** |
| **목표 운영 지표** | 일일 참가자 ~100명, 평균 플레이 타임 1분 ~ 1분 20초, 시간당 15~20명 회전 |
| **개발 엔진** | Unity 6 (`6000.6.0f1`) + URP (Universal Render Pipeline) |
| **시연 장비** | 플레이용 태블릿 PC 또는 노트북 1~2대 단독 운용 (대형 모니터 배선 없는 가볍고 효율적인 운영) |

## 🎬 3. 단일 맵(등교길) 거리별 3대 구역 & 6대 기믹 도감

맵은 **단일 등교길**에서 무한히 진행되며, 이동 거리가 늘어남에 따라 원작 '길건너 친구들'의 대표 기믹들을 대학 캠퍼스 테마로 재해석한 장애물들이 순차적으로 출현합니다.

```
[0m ~ 200m] 도입 구간: 정문 앞 삼거리 ──> [200m ~] 가속 구간: 마의 헐떡고개 ──> [상시] 교수님의 매의 눈
 (고정 지형, 이동 차량, 물웅덩이 널판지)         (캠퍼스 지상철, 전력 질주 지각생)          (3~5초 정체 시 강제 F학점)
```

### 👾 캠퍼스 6대 장애물 도감

| 아이콘 | 장애물 명칭 | 원작 기믹 | 등장 구역 | 동작 패턴 및 특징 |
|:---:|:---|:---:|:---:|:---|
| ⛔ | **방치된 공유 킥보드** / 동기 무리 | 나무, 바위 | 0m ~ | 길을 막는 고정형 지형물. 좌우로 우회하여 통과해야 합니다. |
| 🚌 | **자전거 / 캠퍼스 셔틀버스** | 자동차, 트럭 | 0m ~ | 도로를 일정한 속도로 횡단하며, 타이밍을 맞춰 사이를 건넙니다. |
| 🟫 | **거대 물웅덩이와 널판지/박스** | 강물, 통나무 | 0m ~ | 비 온 뒤 공사구간. 떠다니는 널판지를 밟고 건너며, 화면 밖으로 떠내려가면 탈락합니다. |
| 🚆 | **캠퍼스 관통 지상철** (오토바이) | 기차 | 200m ~ | 바닥에 **선명한 붉은 경고선(1초 점멸)**과 건널목 종소리 후 초고속으로 돌진합니다. |
| 🏃 | **전력 질주하는 타과 지각생** | 경찰차 | 200m ~ | 시각 경고등 없이 **"아악 늦었다!" 비명 소리**와 함께 빠르게 휙 지나가는 소리 의존 장애물입니다. |
| 👨‍🏫 | **교수님의 매의 눈** | 독수리 | 상시 | 안전지대에서 3~5초 이상 지체하거나 화면 밖으로 밀리면 즉시 **강제 F학점(게임오버)**을 부여합니다. |

## 🏆 4. 듀얼 랭킹 & 부스 운영 시스템 (Leaderboard & Booth)

1. **인게임 로컬 TOP 5 랭킹 모달:**
   - 타이틀 화면의 **'🏆 TOP 랭킹 보기'** 버튼을 통해 상위 1~5위 기록을 언제든지 확인 가능합니다.
   - 게임오버 시 성적표 팝업에서 최종 거리(m)와 학점 뱃지(A+, B0, C0, F)를 부여받고 최고 기록 경신 여부를 체크합니다.
2. **부스 현장 [아날로그 화이트보드 랭킹판]:**
   - 부스 입구 대형 화이트보드에 1~10위 기록과 학번/이름을 진행 요원이 수기로 기재합니다.
   - 최고 기록 경신 시 실시간으로 이름을 덮어써 축제 현장감을 극대화합니다.
3. **학점별 축제 보상 체계:**
   - **A+ (500m 이상):** 축제 음료 쿠폰 / 간식 세트
   - **B ~ C (200 ~ 499m):** 사탕 / 젤리
   - **F 학점 (200m 미만):** '재수강 확정' 위로 스티커
