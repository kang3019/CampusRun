## 📖 1. 프로젝트 개요 (Project Overview)

**'지각 5분전 (CampusRun)'**은 소프트웨어학과 축제 부스 전시(10월 16일)를 목표로 제작된 대학생 공감 3D 탭 아케이드 게임입니다.  
볼거리와 즐길 거리가 많은 축제 현장 환경에 맞추어, **1인당 1분 내외의 짧고 직관적인 조작감**과 **기록 경신을 통한 랭킹 경쟁**을 유도하도록 기획되었습니다.

|:---|:---|
| **프로젝트명** | **지각 5분전 - 1교시를 향해 달려라!** (영문 코드명: `CampusRun`) |
| **장르 / 플랫폼** | 3D 하이퍼캐주얼 탭 아케이드 / Windows PC (태블릿 PC & 노트북 최적화) |
| **핵심 마일스톤** | **🎯 2026년 10월 16일 축제 부스 전시 완성 빌드 릴리스** |

| **시연 장비** | 플레이용 태블릿 PC 또는 노트북 1~2대 단독 운용 (외부 대형 모니터 없이 간결한 세팅) |

## 🎮 3. 게임 메커니즘 및 장애물 도감 (Mechanics)

'길건너 친구들'의 대표적인 기믹들을 대학 캠퍼스 일상 테마로 1:1 재해석하여 적용했습니다.

```
[등교길 출발] ──(0m~)──> [킥보드 & 셔틀버스] ──(200m~)──> [배달 오토바이 급습] ──(지체 시)──> [교수님의 매의 눈]
```

### 👾 캠퍼스 장애물 도감
1. **방치된 공유 킥보드 / 잡담하는 동기 무리 (원작: 나무/바위)**
   - **유형:** 고정형 길막 장애물 (0m~)
   - **패턴:** 레인 위 통로를 막고 서 있으며, 좌우로 우회하여 지나가야 합니다.
2. **자전거 / 셔틀버스 (원작: 자동차/트럭)**
   - **유형:** 일반 횡단 이동물 (0m~)
   - **패턴:** 일정한 속도로 도로를 지나가며, 지나간 직후 타이밍에 맞춰 안전하게 건너야 합니다.
3. **배달 오토바이 (원작: 기차)**
   - **유형:** 경고 후 초고속 돌진 (200m 이후 추가 등장)
   - **패턴:** 바닥 레인에 **붉은색 경고 궤적**이 점멸하고 다급한 경적 소리가 울린 뒤 눈 깜짝할 새 돌진합니다.
4. **교수님의 매의 눈 (원작: 독수리)**
   - **유형:** 상시 타임아웃 즉사 기믹 (글로벌)
   - **패턴:** 안전 레인에 3~5초 이상 머뭇거리거나 카메라 밖으로 밀려나면 교수님이 등장해 즉시 **강제 F학점(게임오버)**을 부여합니다.

## 🏆 4. 듀얼 랭킹 & 부스 운영 시스템 (Leaderboard & Booth)

1. **인게임 로컬 랭킹 모달:**
   - 타이틀 화면의 **'🏆 TOP 랭킹 보기'** 버튼을 통해 상위 1~5위 기록을 언제든지 확인 가능합니다.
   - 게임오버 시 성적표 팝업에서 최종 거리(m)와 학점 뱃지(A+, B0, C0, F)를 부여받고 최고 기록 경신 여부를 체크합니다.
2. **부스 현장 [아날로그 화이트보드 랭킹판]:**
   - 부스 입구에 설치된 대형 화이트보드에 1~10위 기록과 학번/이름을 진행 요원이 수기로 기재합니다.
   - 최고 기록 경신 시 실시간으로 이름을 덮어써 축제 현장감을 고조시킵니다.
3. **학점별 축제 보상 체계:**
   - **A+ (500m 이상):** 축제 음료 쿠폰 / 간식 세트
   - **B ~ C (200 ~ 499m):** 사탕 / 젤리
   - **F 학점 (200m 미만):** '재수강 확정' 위로 스티커
